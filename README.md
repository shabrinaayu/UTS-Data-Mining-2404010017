Model klasifikasi untuk memprediksi kualitas anggur (quality) dari
sifat kimianya, memakai dataset Wine Quality.

## Isi repo
- UTS DataMining_2404010017.ipynb : notebook analisis lengkap beserta interpretasi
- model_wine.pkl           : model yang sudah dilatih (Extra Trees)
- hasilprediksi_017.csv    : hasil prediksi data testing (kolom Id dan Quality)
- data_training.csv, data_testing.csv : dataset yang dipakai

## Ringkasan
Model terbaik adalah Extra Trees dengan akurasi cross-validation sekitar 65%.
